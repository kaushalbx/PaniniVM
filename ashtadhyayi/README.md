# Module `:ashtadhyayi`

Executable Aṣṭādhyāyī Sūtra catalog and rule implementation library.

## Overview

The `:ashtadhyayi` module implements 474+ executable sūtras across all 8 Adhyāyas:
- **Sandhi (Phonology)**: Pūrvarūpa (6.1.109), Visarga/Lopa (6.1.132, 8.3.14, 8.3.17, 8.3.22), Parasavarṇa (8.4.59, 8.4.60), Dīrgha (6.3.111).
- **Samāsa (Compounds)**: Avyayībhāva (2.1.6), Tatpuruṣa (2.1.24, 2.1.37, 2.2.8), Bahuvrīhi (2.2.24), Dvandva (2.2.29).
- **Kāraka (Semantic Roles)**: 100% full coverage of all 33 Adhyāya 1.4 Kāraka saṁjñās.
- **Vibhakti (Case Endings)**: 100% full coverage of all 64 Adhyāya 2.3 Vibhakti sūtras.
- **Subanta & Tiṅanta**: Nominal stem and verbal inflection rules.
