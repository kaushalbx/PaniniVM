# Module `:dhatupatha`

Complete 10-Gaṇa Dhātupāṭha root catalog.

## Overview

Contains typed Kotlin definitions for roots across all 10 traditional gaṇas:
1. `BhvadiDhatus` (भ्वादिगण - 1st class)
2. `AdadiDhatus` (अदादिगण - 2nd class)
3. `JuhotyadiDhatus` (जुहोत्यादिगण - 3rd class)
4. `DivadiDhatus` (दिवादिगण - 4th class)
5. `SvadiDhatus` (स्वादिगण - 5th class)
6. `TudadiDhatus` (तुदादिगण - 6th class)
7. `RudhadiDhatus` (रुधादिगण - 7th class)
8. `TanadiDhatus` (तनादिगण - 8th class)
9. `KryadiDhatus` (क्र्यादिगण - 9th class)
10. `CuradiDhatus` (चुरादिगण - 10th class)

Preserves upadeśa surface, *it-markers*, pada metadata (Parasmaipada, Ātmanepada, Ubhayapada), and Sanskrit/Hindi semantic glosses.
