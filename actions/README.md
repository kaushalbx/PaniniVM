# Module `:actions`

Action dispatchers and operational interfaces for execution contexts.

## Overview

Defines operational action contracts:
- `PaniniAction`: Abstract base for executable runtime actions.
- `DhatuAction`: Action dispatcher bound to specific Dhātu root entries.
- `SubantaAction`: Action dispatcher for nominal subanta operations.
- `TingantaAction`: Action dispatcher for verbal tiṅanta operations.
- `SankhyaAction`: Action dispatcher for arithmetic and numerical transformations.
