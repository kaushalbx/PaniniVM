# Ancient Indian Numeral Systems Demo in PaniniVM
# Demonstrating Kaṭapayādi (कटपयादि) and Āryabhaṭīya (आर्यभटीय) encodings

# -----------------------------------------------------------------------------
# Example 1: Kaṭapayādi (कटपयादि) System
# "माधव" in Kaṭapayādi: म(5) ध(9) व(4) -> 495
# "खग" in Kaṭapayādi: ख(2) ग(3) -> 32
# Step 1: Add 495 (माधव) and 32 (खग) = 527 (सप्तविंशत्यधिकपञ्चशतम्)
# -----------------------------------------------------------------------------
माधवं खगं च योजय ।
योगस्य फलं मुद्रय ॥

# -----------------------------------------------------------------------------
# Example 2: Āryabhaṭīya (आर्यभटीय) System
# "गि" in Āryabhaṭīya: ग(3) + इ(10^2=100) -> 300
# "चयि" in Āryabhaṭīya: च(6)*100 + य(30)*100 = 600 + 3000 -> 3600
# Step 2: Multiply 300 (गि) by 3600 (चयि) = 1,080,000
# -----------------------------------------------------------------------------
गिं चयिं च गणय ।
गाणस्य फलं मुद्रय ॥
