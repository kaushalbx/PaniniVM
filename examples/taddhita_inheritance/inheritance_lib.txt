# Declare domain scope 'गणित'
गणितः इति अधिकारः ।

# Define parent method 'वर्द्धनम्' on class 'गणित' (Adds 1st arg and 2nd arg using pure Pāṇinian पूरण-प्रत्ययाः: अमच्, तीय)
# Sūtra 5.2.58 तस्य पूरणे अमच् -> प्रथ् + अमच् + अम् (1st parameter)
# Sūtra 5.2.54 द्वित्रिभ्यां तीयस्य -> द्वि + तीय + अम् (2nd parameter)

प्रथ्+अमच्+अम् द्वितीयम् च युज्यस्व ।
मुद्रय फलम् ॥
