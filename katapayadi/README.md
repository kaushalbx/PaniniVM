# Module `:katapayadi`

Kaṭapayādi numerical cipher encoder and decoder.

## Overview

Implements the classical Kaṭapayādi alphanumeric cipher system (*नञावचश्च शून्यानि*):
- Maps Sanskrit consonants to digits 0–9 (`क-ट-प-य` = 1, `ख-ठ-फ-र` = 2, etc.).
- Converts Sanskrit words and mnemonic verses into numerical values.
