# Module `:ganapatha`

Gaṇapāṭha nominal list registry module.

## Overview

Maintains nominal stem lists (*Gaṇas*) referenced by Aṣṭādhyāyī sūtras:
- `SarvadiGana` (सर्वादीनि सर्वनामानि 1.1.27)
- `SvaradiGana` (स्वरादिनिपातमव्ययम् 1.1.37)
- `PraGana` (प्रादयः 1.4.58)
- Additional lists for Samāsa and Taddhita derivations.
