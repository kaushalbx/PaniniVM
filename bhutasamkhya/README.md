# Module `:bhutasamkhya`

Bhūtasamkhyā symbolic noun numerical decoder.

## Overview

Decodes classical Indian symbolic noun numeral systems (*Bhūtasamkhyā*):
- Symbolic noun mappings (e.g. `नेत्र` = 2, `अग्नि` = 3, `वेद` = 4, `रसा` = 6, `ग्रह` = 9).
- Enforces the right-to-left digit placement convention (*अङ्कानां वामतो गतिः*).
