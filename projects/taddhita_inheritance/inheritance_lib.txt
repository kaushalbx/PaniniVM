# तद्धित ग्रन्थ — Parent Class Library (गणित)

# Declare domain scope 'गणित'
गणितः इति अधिकारः ।

# Define parent method 'वृध् + ल्युट् + सुँ' (वर्द्धनम्) on class 'गणित' (Dhātu: वृध् + Kṛt: ल्युट्)
# Sūtra 5.2.58 तस्य पूरणे अमच् -> प्रथ् + अमच् + अम् (1st parameter)
# Sūtra 5.2.54 द्वित्रिभ्यां तीयस्य -> द्वि + तीय + अम् (2nd parameter)
गणितस्य वर्धनम् इति प्रक्रिया अस्ति ।
प्रथमं द्वितीयं च युन्ग्धि ।
मुद्रय फलम् ॥
